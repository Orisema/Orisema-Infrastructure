# Como contribuir

Obrigado por querer cultivar a Orisema!

Nesta fase, priorizamos revisão de documentação, discussões sobre escopo, testes e propostas arquiteturais.

1. Abra uma issue descrevendo o problema ou sugestão.
2. Discuta mudanças grandes antes de implementá-las.
3. Nunca envie credenciais, dados pessoais ou código corporativo sem autorização.
4. Prefira mudanças pequenas, documentadas e reproduzíveis.
5. Trate os demais colaboradores com respeito.

**Atenção:** a licença de código ainda será definida. Evite enviar contribuições substanciais de código até a publicação do arquivo `LICENSE` e das regras de contribuição correspondentes.
